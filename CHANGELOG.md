# Changelog

Все заметные изменения продукта будут описываться здесь.

Формат основан на Keep a Changelog, версии следуют Semantic Versioning.

## [0.12.1] - 2026-06-25

### Changed

- В README добавлена ссылка на публичный Vercel-деплой.

## [0.12.0] - 2026-06-25

### Added

- Конфигурация Vercel для корректной работы прямых ссылок и обновления страниц React Router.

### Changed

- README переписан в более короткий публичный формат с описанием возможностей, приватности, запуска и деплоя.
- Версия проекта обновлена для первого публичного деплоя.

## [0.11.1] - 2026-06-25

### Changed

- Улучшена мобильная навигация: пункты меню не переносятся и доступны через горизонтальную прокрутку.
- Обновлен внешний вид истории записей на мобильных и десктопных экранах.
- Улучшена видимость placeholder-текста в формах.

## [0.11.0] - 2026-06-25

### Added

- Ограничение размера импортируемого файла резервной копии.
- Дополнительные проверки структуры, дат, чисел, названий и пользовательских продуктов при импорте.

### Changed

- Импорт резервной копии строже отклоняет поврежденные или некорректные данные.
- Сохранена поддержка реальных экспортированных записей с `Date.now()` в качестве `id`.

## [0.10.1] - 2026-06-22

### Added

- Страница обратной связи с переходом во внешнюю форму Tally.
- Ссылка на обратную связь в основной навигации.
- Privacy-пояснение об отсутствии автоматической передачи данных дневника.
- Безопасное открытие внешней формы в отдельной вкладке.

## [0.10.0] - 2026-06-21

### Added

- Страница управления данными с локальным экспортом и импортом.
- JSON-резервная копия записей, цели калорий и пользовательских продуктов.
- Версионирование формата резервной копии.
- Безопасный парсинг и проверка структуры импортируемых данных.
- Полное восстановление Redux state из корректной резервной копии.
- Повторный выбор одного и того же файла после импорта.

## [0.9.0] - 2026-06-20

### Added

- Отдельная страница пользовательских продуктов.
- Добавление продуктов с ккал и БЖУ на 100 г.
- Сохранение пользовательского справочника в `localStorage`.
- Пользовательские продукты в подсказках и быстром вводе.
- Проверка дубликатов по названию среди встроенных и пользовательских продуктов.
- Список пользовательских продуктов с подтверждением удаления.

## [0.8.0] - 2026-06-13

### Added

- Макронутриенты в справочнике продуктов: белки, жиры и углеводы на 100 г.
- Расчет БЖУ для записи по весу продукта.
- Отображение БЖУ в записи еды и дневной сводке.
- Дневной selector для итоговых БЖУ.
- Миграция старых записей из `localStorage` с дефолтными значениями БЖУ.

## [0.7.0] - 2026-06-08

### Added

- Быстрый ввод еды вроде `гречка 100 г`.
- Парсер быстрого ввода с поддержкой граммов, килограммов, миллилитров, литров и штук.
- Автоматическое заполнение веса из быстрого ввода.
- Поиск подсказок по очищенному названию продукта.
- Автозаполнение ккал на 100 г, если быстрый ввод дал одно совпадение в справочнике.

## [0.6.0] - 2026-06-06

### Added

- Локальный справочник продуктов с калорийностью на 100 г.
- Подсказки продуктов при вводе названия еды.
- Выбор продукта из подсказок с автозаполнением названия и ккал на 100 г.
- Оформление выпадающего списка подсказок.

## [0.5.0] - 2026-06-03

### Added

- Отдельная страница недельной статистики.
- Недельные итоги: общая сумма калорий, среднее за день и дни с превышением цели.
- Список 7 дней с калориями, процентом от цели, статусом и progress bar.
- Пустое состояние для недели без записей.

## [0.4.0] - 2026-05-24

### Added

- Дневная цель калорий с хранением в `localStorage`.
- Donut-диаграмма прогресса к дневной цели.
- Отображение процента от цели, остатка калорий, выполненной цели и превышения.
- Redux slice для цели калорий и типизированная утилита расчета прогресса.

## [0.1.0] - 2026-05-02

### Added

- Первый рабочий прототип Food Tracker.
- Добавление еды с количеством калорий.
- Подсчет общего количества калорий.
- Список добавленных продуктов.
- Базовая валидация формы.
