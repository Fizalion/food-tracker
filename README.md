# LogFood

LogFood — дневник питания для учета еды, калорий, БЖУ, дневной цели и пользовательских продуктов.

Приложение работает в браузере и хранит данные локально на устройстве пользователя. В текущей версии backend не используется.

## Возможности

- Добавление еды с весом и калорийностью на 100 г.
- Автоматический расчет калорий, белков, жиров и углеводов.
- Дневная цель калорий и прогресс за день.
- Подсказки продуктов из встроенного и пользовательского справочника.
- Добавление и удаление пользовательских продуктов.
- Быстрый ввод вроде `гречка 100 г`.
- История записей по датам.
- Недельная статистика.
- Экспорт и импорт локальной резервной копии в JSON.
- Страница обратной связи через внешнюю форму Tally.

## Приватность

LogFood хранит записи дневника, цель калорий и пользовательские продукты в `localStorage` браузера.

В текущей версии данные дневника не отправляются на сервер. Резервная копия создается и импортируется локально в браузере.

Форма обратной связи открывается в Tally. Через Tally отправляется только информация, которую пользователь сам вводит в форму.

## Маршруты

- `/` — дневник
- `/day/:date` — дневник за выбранную дату
- `/history` — история
- `/statistics` — недельная статистика
- `/products` — пользовательские продукты
- `/data` — экспорт и импорт данных
- `/feedback` — обратная связь

## Локальный запуск

Установить зависимости:

```bash
npm install
```

Запустить dev-сервер:

```bash
npm run dev
```

Если PowerShell блокирует `npm.ps1`, можно использовать:

```bash
npm.cmd run dev
```

## Проверка

Линтер:

```bash
npm.cmd run lint
```

Production build:

```bash
npm.cmd run build
```

## Деплой

Проект подготовлен к деплою на Vercel.

Рекомендуемые настройки:

- Framework preset: Vite
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`

Файл `vercel.json` перенаправляет маршруты на `index.html`, чтобы страницы React Router работали после обновления браузера или открытия прямой ссылки.
